## 🚀 About Me

- 🤖 Robotics Engineer focused on **Perception**, **Navigation** and **AI** for embodied systems.
- 🦿 I build autonomy for **humanoids**, **quadrupeds**, **AMRs** and **drones** — SLAM and multi-sensor fusion through to whole-body control.
- 🎓 **M.Sc. Robotic Systems Engineering** @ **RWTH Aachen University** · BTech Mechanical Engineering.
- ⚡ I turn models into **real-world hardware deployments** — C++ perception pipelines accelerated with **SIMD / SIMT and CUDA**.
- 🌱 Interests: ROS 2, SLAM, sensor fusion, VLA models, imitation learning, sim-to-real.
- 💬 Ask me about **ROS / ROS 2, perception, navigation, SLAM and simulation**.
